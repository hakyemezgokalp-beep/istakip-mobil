# İşTakip Mobil

KGM 7. Bölge Müdürlüğü İşTakip programının telefon görüntüleyicisi. Bu depoda hiçbir veri yoktur; veri, programdaki "Telefon Verisi" düğmesiyle üretilen .istakip dosyasıyla telefonda yüklenir ve yalnızca o telefonda saklanır.

**Bu depoya veri dosyası (.istakip, .json) yüklemeyin.**
